# CF LOCK

Android kiosk latch. Dark screen, one numeric field, one accepted code.

Kotlin, no Compose, Android 7.0 through Android 16. `app/` holds the source,
`app/build.sh` builds it headless, `app/dist/CF-LOCK.apk` is the signed output.

Read `app/README.md` for the build, the arming steps, how each hold layer works,
and the removal paths.
